# GoRest Dashboard
Тестовое задание на стажировку frontend-dev.
Приложение для просмотра данных пользователей и постов на основе GoRest API.

## Технологии
- **React 18** (TypeScript)
- **UI Kit:** Consta (@consta/uikit)
- **State Management:** React Context API
- **Routing:** React Router Dom v7
- **HTTP Client:** Axios

## Функционал
- Авторизация по Access Token (GoRest)
- Две страницы с интерактивными таблицами, содержащими списки пользователей и постов 
  клик по строке:
  * при нажатии на строку пользователя открывается карточка с его информацией
  * при переходе на пост открывается карточка с текстом поста и комментариями
- Пагинация 
  * номера страниц
  * переключение "вперед/назад"
  * выбор количества элементов на странице (10/25/50)
- Гибкая верстка (в том числе поддержка разрешений 1024px - 1920px)

## Инструкция по запуску
**Системные требования**
понадобится:
1. Node.js версии 18.0 или выше
2. Менеджер пакетов npm (идет в комплекте с Node.js)
3. Любой браузер (в том числе Яндекс.Браузер и Microsoft Edge)

**Установка проекта**
1. Клонируйте репозиторий:

2. Перейдите в папку проекта:
cd 

3. Установите зависимости:
npm install --legacy-peer-deps

4. запустите в режиме разработки
npm run dev

После запуска проект будет доступен по адресу: http://localhost:5173 (или другому порту, указанному в терминале)

**Как пользоваться приложением**
1. Получите свой Access Token на сайте https://gorest.co.in/ 
2. Введите полученный токен в поле ввода на главной странице (приложение выполнит проверку токена через API)

3. Навигация:
- Сверху находится переключатель между списками пользователей и постов, используйте его, чтобы переключаться между страницами
- Для перехода на карточку с детальной информацией пользователя или поста, нажмите на любую строку в таблице
- Используйте пагинацию под таблицей для удобной навигации
